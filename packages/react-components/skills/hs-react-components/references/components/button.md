# Button

> Actions with a text label, optionally with an icon.

**Import**

```tsx
import { Button } from "@health-samurai/react-components";
```

**Props / states**

| Prop | Options | Default |
| --- | --- | --- |
| `variant` | `primary` \| `secondary` \| `link` \| `ghost` | `primary` |
| `size` | `regular` \| `small` | `regular` |
| `danger` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
