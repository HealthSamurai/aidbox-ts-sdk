# Alert

> Persistent inline message: info, warning, critical, success.

**Import**

```tsx
import { Alert, AlertTitle, AlertDescription } from "@health-samurai/react-components";
```

**Props / states**

| Prop | Options | Default |
| --- | --- | --- |
| `variant` | `critical` \| `warning` \| `info` \| `neutral` \| `success` | `info` |
| `vivid` | `boolean` | `false` |
| `icon` | `boolean` | `true` |

**Composition**

`Alert` · `AlertTitle` · `AlertDescription`
