# Combobox / MultiCombobox

**Import**

```tsx
import { Combobox, MultiCombobox } from "@health-samurai/react-components";
```

**Props / states**

| Prop | Options | Default |
| --- | --- | --- |
| `multi` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
