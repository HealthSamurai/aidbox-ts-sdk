# Switch

> Toggling a setting that takes effect immediately.

**Import**

```tsx
import { Switch } from "@health-samurai/react-components";
```

**Props / states**

| Prop | Options | Default |
| --- | --- | --- |
| `size` | `regular` \| `small` | `regular` |
| `disabled` | `boolean` | `false` |
