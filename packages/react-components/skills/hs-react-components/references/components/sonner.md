# Toast / Sonner

> Temporary dismissible notification that appears and auto-hides.

**Import**

```tsx
import { Toaster, toast } from "@health-samurai/react-components";
```

**Props / states**

| Prop | Options | Default |
| --- | --- | --- |
| `variant` | `info` \| `error` | `info` |
| `closeButton` | `boolean` | `false` |
| `hasAction` | `boolean` | `false` |
| `hasSecondaryAction` | `boolean` | `false` |

**Composition**

`Toaster` · `toast`
