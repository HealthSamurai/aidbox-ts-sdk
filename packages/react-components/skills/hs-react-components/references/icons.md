# Icons

The design system ships 10 built-in icon components, imported from
`@health-samurai/react-components`:

`BackboneElementIcon` · `ComplexTypeIcon` · `ExtensionIcon` · `PinIcon` · `PlayIcon` · `ReferenceIcon` · `ResourceIcon` · `SquareFunctionIcon` · `TypCodeIcon` · `UnionIcon`

For general-purpose icons use `lucide-react` (already a dependency).
